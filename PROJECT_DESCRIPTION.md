## Detailed (100 words)
Code Olympics 2026 GitHub Scanner is an automated constraint validation tool that analyzes entire repositories through the GitHub API. It validates all four dimensions: D1 (core constraints like one-loop warrior), D2 (line budgets from 50-650), D3 (project domains), and D4 (10 official languages). The scanner detects actual file types, counts loops using regex patterns, measures code lines, and provides instant pass/fail results with specific violation details. Built as a meta-compliant submission, the tool demonstrates the constraints it validates—achieving zero loops through functional programming (Promise.all, .map, .filter) and staying under 300 lines with pure JavaScript.

## For Submission Form (150 words)
This project is a GitHub repository scanner that automates constraint validation for Code Olympics 2026 submissions. Participants can enter any GitHub repo URL, select their 4D constraint combination, and receive instant validation results.

**Key Features:**
- Scans entire repositories via GitHub API
- Validates D1 (8 core constraints), D2 (8 line budgets), D3 (10 domains), D4 (10 languages)
- Detects loops, imports, variables, and functions using regex patterns
- Identifies programming languages from file extensions
- Provides detailed violation reports with exact counts
- Supports both main and master branches
- Zero dependencies—single HTML file

**Meta-Compliance:**
The tool itself follows Code Olympics constraints:
- 0 loops (uses Promise.all for parallel processing)
- 282 lines of code (under 300 budget)
- Full data processing pipeline (fetch → parse → validate → render)
- Pure JavaScript with async-first architecture

This demonstrates constraint-compliant code while providing genuine utility to all participants.
