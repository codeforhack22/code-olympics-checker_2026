## 📝 FULL SCRIPT (Read exactly as written)

---

### [0:00 - 0:15] OPENING

*"Code Olympics 2026 has strict constraints. One loop maximum. Three hundred lines of code. Specific domains and languages. How do you know if your submission passes?*

*Meet the GitHub Scanner - a tool that validates all constraints automatically."*

**[Pause 1 second]**

---

### [0:15 - 0:30] THE PROBLEM

*"Manually checking constraints is tedious. You have to count every loop, every line, across multiple files. One mistake and your submission fails.*

*There has to be a better way."*

**[Pause 1 second]**

---

### [0:30 - 0:50] THE SOLUTION

*"Enter any GitHub repository URL. Select your 4D constraint combination.*

*D1 for core constraints like one-loop warrior.*

*D2 for line budget up to six hundred fifty lines.*

*D3 for your project domain.*

*And D4 for your programming language.*

*Then click scan."*

**[Pause 1 second]**

---

### [0:50 - 1:10] THE MAGIC

*"The scanner fetches your entire repository, analyzes all source files in parallel, and validates every constraint in seconds.*

*It checks your actual code - counting loops, measuring lines, detecting your language from file extensions."*

**[Pause 1 second]**

---

### [1:10 - 1:30] THE META-ANGLE

*"Here's the twist - this tool is itself constraint-compliant.*

*Zero loops using functional programming. Two hundred eighty-two lines of pure JavaScript.*

*It validates constraints while demonstrating them. That's meta-validation."*

**[Pause 1 second]**

---

### [1:30 - 1:45] KEY FEATURES

*"It supports all ten official languages. Works with both main and master branches. Shows exact violations with helpful messages.*

*Zero setup - just open the URL and start scanning."*

**[Pause 1 second]**

---

### [1:45 - 2:00] CALL TO ACTION

*"Try it now at code-olympics-checker-2026 dot vercel dot app.*

*Validate your submission before you submit. The code is open source on GitHub.*

*Built for Code Olympics 2026 - where constraints meet creativity."*

**[End]**

## 🎬 RECORDING TIPS

1. **Warm up your voice** - Read the script 2-3 times before recording
2. **Stand up** - Better breath control and energy
3. **Smile while talking** - It comes through in your voice
4. **Record in a quiet room** - Use blankets/pillows to reduce echo
5. **Stay hydrated** - Have water nearby
6. **Do multiple takes** - Record each section 2-3 times
7. **Leave pauses** - Easier to edit later

## 🎯 SCRIPT VARIATIONS

### If you want to sound more casual:

Replace:
- "Meet the GitHub Scanner" → "I built a GitHub Scanner"
- "There has to be a better way" → "So I built a better way"
- "Here's the twist" → "But here's the cool part"
- "Try it now" → "Check it out"

### If you want to sound more professional:

Replace:
- "Here's the twist" → "The unique aspect"
- "That's meta-validation" → "This demonstrates meta-validation"
- "Zero setup" → "No configuration required"
- "Try it now" → "Access the tool"
