## Screen Recording Tips

- **Tool:** OBS Studio (free), Loom, or QuickTime (Mac)
- **Resolution:** 1920x1080 or 1280x720
- **Length:** 3-5 minutes max
- **Audio:** Clear voiceover explaining what you're doing
- **Pacing:** Slow enough to follow, fast enough to stay engaging

## What to Show

✅ The tool working with multiple test cases  
✅ Different constraint combinations  
✅ The meta-validation (tool checking itself)  
✅ The one-loop architecture (show the code)  
✅ Multi-language support  

❌ Don't spend time on setup or installation (there is none)  
❌ Don't read the README aloud (judges can read)  
❌ Don't apologize for limitations (save that for self-assessment)
